# Чат-бот на n8n

Готовый workflow `chat-bot-workflow.json`: встроенный веб-чат n8n → AI-агент на Claude → ответ в чат. Диалог помнит последние 10 сообщений.

## Состав

| Нода | Назначение |
| --- | --- |
| Chat Trigger | Принимает сообщения из встроенного чат-виджета n8n |
| AI Agent | Формирует ответ по системному промпту |
| Anthropic Chat Model | Модель `claude-sonnet-5-5` |
| Window Buffer Memory | Хранит историю диалога по `sessionId` |

## Установка

1. В n8n: **Workflows → Import from File** и выберите `chat-bot-workflow.json`.
2. Откройте ноду **Anthropic Chat Model** и создайте credential типа *Anthropic API* с вашим API-ключом. Выберите его в ноде.
3. Нажмите **Save**, затем **Publish** (или переключите **Active**).
4. Откройте ссылку **Chat** из ноды Chat Trigger и напишите боту.

## Настройка

- Поведение бота задаётся в поле **System Message** ноды AI Agent.
- Другая модель: поменяйте значение в **Anthropic Chat Model**.
- Длина памяти: параметр **Context Window Length** в Window Buffer Memory.
- Другой канал (Telegram, Slack и т.д.): замените Chat Trigger на нужный триггер, остальные ноды оставьте.

## Дополнительные workflow

| Файл | Что делает | Расписание |
| --- | --- | --- |
| `error-alert-workflow.json` | При ошибке любого workflow шлёт администратору сообщение в WhatsApp | по событию |
| `calendar-sync-workflow.json` | Находит в Google Calendar события, которых нет в таблице (ручные записи), и добавляет их в «Записи» | каждые 15 минут |
| `reminders-workflow.json` | Отправляет клиентам напоминание о записи на завтра и помечает строку «напоминание отправлено» | ежедневно в 18:00 |

Настройка:
1. Импортируйте все три файла.
2. Замените плейсхолдеры: `REPLACE_WITH_SHEET_ID`, `REPLACE_WITH_CALENDAR_ID`, `REPLACE_ADMIN_PHONE` (номер администратора, цифры с кодом страны), `REPLACE_*_CREDENTIAL_ID` (выберите credentials в нодах).
3. В основном боте и в обоих фоновых workflow откройте **Settings → Error Workflow** и выберите «Ошибки: уведомление администратора». Тогда ошибки будут приходить администратору.
4. Проверьте часовой пояс в **Settings → Timezone** (в файлах стоит `Europe/Moscow`).
5. Включите workflow через **Active**.

Важно про таблицу:
- Столбец `event_id` нужен во всех строках. Строки от бота должны записывать сюда ID события Google Calendar, иначе синхронизация продублирует запись, а напоминания для неё не сработают.
- Столбец «Дата» держите как обычный текст в формате `ГГГГ-ММ-ДД`, иначе фильтр напоминаний не сравнит даты.
- Ручные записи из календаря попадают в таблицу без телефона. Напоминания им не уйдут, пока в строке не заполнен столбец «Телефон».
- Отменённые в календаре события синхронизация не удаляет и не переводит в статус «отменено». Эту часть сделаем отдельно, если понадобится.
- Whapi: формат webhook и эндпоинт `gate.whapi.cloud/messages/text` взяты из общего знания об API, а не из документации сервиса. Перед запуском сверьте их на whapi.cloud.

## Важно

- В JSON стоит плейсхолдер `REPLACE_WITH_CREDENTIAL_ID`. n8n заменит его при выборе credential в ноде; в коде API-ключи не хранятся.
- Версии нод соответствуют n8n 1.x с пакетом LangChain-нод. Если импорт ругается на версию, обновите n8n или выберите ноды вручную по тем же типам.
