# Обменный пункт

Покупка и продажа валюты: курсы, касса, журнал операций, прибыль.
Работает на Python 3.10+ без внешних зависимостей.

## Как это работает

Все операции описаны с точки зрения обменного пункта:

| Операция | Что происходит | Курс |
|---|---|---|
| `buy`  | пункт **покупает** валюту у клиента и выдаёт ему базовую валюту | курс покупки |
| `sell` | пункт **продаёт** валюту клиенту и получает от него базовую валюту | курс продажи |

- Курс задаётся за 1 единицу валюты в базовой валюте; курс покупки не может быть выше курса продажи.
- Перед каждой операцией проверяется остаток в кассе — продать больше, чем есть, нельзя.
- Суммы округляются до копеек в пользу пункта: выплата клиенту — вниз, получение от клиента — вверх.
- Для каждой валюты хранится средняя себестоимость остатка (средневзвешенный курс покупки).
  Прибыль при продаже = (курс продажи − себестоимость) × сумма.
- Вносимая в кассу иностранная валюта получает себестоимость по текущему курсу покупки.

## Командная строка

```bash
python -m exchange init --base RUB          # создать пункт (файл exchange_data.json)
python -m exchange deposit RUB 500000       # внести наличные в кассу
python -m exchange rate USD 90.50 92.00     # курс: покупка / продажа
python -m exchange rates                    # показать курсы

python -m exchange quote buy USD 100        # рассчитать без проведения операции
python -m exchange buy USD 1000             # купить у клиента 1000 USD
python -m exchange sell USD 300             # продать клиенту 300 USD

python -m exchange balance                  # остатки и себестоимость
python -m exchange history --limit 10       # журнал операций
python -m exchange report                   # оборот и прибыль
python -m exchange withdraw RUB 10000       # изъять наличные
python -m exchange unrate EUR               # удалить курс
```

Файл с данными можно указать через `--data путь.json` или переменную окружения `EXCHANGE_DATA`.

Пример:

```
$ python -m exchange buy USD 1000
Куплено 1000.00 USD по 90.5. Выдать клиенту: 90500.00 RUB
$ python -m exchange sell USD 300
Продано 300.00 USD по 92. Получить от клиента: 27600.00 RUB
Прибыль по операции: 450.00 RUB
```

## Использование из кода

```python
from exchange import ExchangeOffice

office = ExchangeOffice("RUB")
office.deposit("RUB", "500000")
office.set_rate("USD", "90.50", "92.00")

office.buy("USD", "1000")       # Transaction(base_amount=Decimal('90500.00'), ...)
tx = office.sell("USD", "300")
print(tx.base_amount, tx.profit)  # 27600.00 450.00
```
